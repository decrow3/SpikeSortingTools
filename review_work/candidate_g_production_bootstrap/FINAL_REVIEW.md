## Exact remaining blockers

1. **Installed unit identity is fail-open.** Canonical file location plus a release-supplied digest is not reviewed-byte identity. `validate_unit_text` accepts any unit containing a bootstrap script-name substring and no banned directive. An arbitrary `ExecStart` with the marker only in a comment passed independently.
2. **Writable cache accounting is incomplete.** Torch, XDG and Matplotlib caches are writable beneath the attempt but absent from `categories()`. A known-answer fixture wrote 300 bytes there while the sampler categorized zero bytes.
3. **The production smoke is not executed-source bound.** Its systemd unit invokes `/tmp/.../source/bootstrap_smoke_entry_v4.py`; no pre-execution receipt hashes the temporary source closure, and it bypasses `bootstrap_production_entry_v4` and `release_gate_v4`. The immutable result proves that some smoke completed with the reported properties, not that the reviewed production entry/gate bytes produced it.

The cheapest adequate repair is small: require installed units to equal the sealed templates byte-for-byte; include all writable cache trees in exact storage accounting; and rerun one disposable service from sealed source (or a prehashed temporary closure) through the actual v4 production entry/gate with a non-scientific release fixture. No agglomeration, voltage or GPU compute is needed.
